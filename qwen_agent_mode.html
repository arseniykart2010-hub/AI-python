PyCamp › О платформе

        
Как устроен PyCamp

        

          PyCamp — учебная платформа в духе freeCodeCamp, упакованная в один HTML-файл. Никакой установки,
          серверов и регистрации: открой файл в браузере (или закинь на любой хостинг) и учись. Интернет нужен только один раз —
          чтобы скачать файл.
        

        

          
📚
13 модулей · 60 уроков
Синтаксис, типы данных, строки, условия, циклы, списки, словари, функции, ООП, исключения, файлы, стандартная библиотека, продвинутые темы и итоговый проект.

          
⌨️
Редактор кода в браузере
Подсветка синтаксиса Python, нумерация строк, Tab-отступы, автораскрытие скобок и кавычек, автосохранение черновика.

          
🧪
Автотесты заданий
Каждое задание проверяется набором тестов: статический анализ кода + встроенный мини-интерпретатор выражений Python, который считает результат твоего кода.

          
💾
Прогресс локально
Выполненные уроки и черновики хранятся в localStorage браузера. Можно выгрузить JSON-файл и перенести прогресс на другое устройство.

          
🏆
Сертификат
После 100% курса генерируется именной сертификат — скачивается как HTML и печатается в PDF.

          
🌗
Тёмная и светлая тема
Переключатель в правом верхнем углу, выбор запоминается.

        


        
Как проходить урок

        
    
          
  1. Прочитай теорию и разбери примеры — под каждым блоком кода показан реальный вывод программы.
    2. 
          
  2. Выполни задание в редакторе: стартовый код уже вставлен, его нужно дополнить.
    3. 
          
  3. Нажми «Проверить решение» (или Ctrl+Enter). В консоли появятся результаты тестов.
    4. 
          
  4. Если застрял — нажми «Подсказка», а потом и «Решение». Но лучше сначала подумать самому 🙂
    5. 
          
  5. Когда все тесты зелёные, урок автоматически помечается пройденным, и можно идти дальше.
    6. 
        


        
⚠️

          
Про ограничения встроенной проверки. Тесты выполняются на JavaScript-движке внутри страницы,
          а не на настоящем CPython. Интерпретатор понимает выражения Python (арифметика, строки, списки, словари, множества,
          срезы, comprehensions, вызовы встроенных функций) и статически проверяет структуру кода. Для запуска реальных программ
          используй локальный Python или онлайн-песочницы — ссылки ниже.
